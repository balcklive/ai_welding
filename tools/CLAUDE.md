# CLAUDE.md — tools/

一次性/本地辅助脚本（不入运行时，不参与打包）。用 uv 管理 Python 环境（`uv run <script>`）。

## 文件

- `generate_training_signal.py`：生成确定性训练信号 fixture——写 `data/synthetic_training_signal.csv`（500 行，0.5s，列 `time/Current/Voltage/GasSpeed/WireSpeed`，起弧 0.10~0.44s 内电流/电压有值、其余 0），供 Playwright 训练流程用真实 CSV 导入。纯标准库（csv/math/pathlib），无第三方依赖。
- `browser-history-e2e.mjs`：浏览器历史回归（Node + Playwright，阶段一 2026-09-14）。断言深链、后退/前进往返、刷新停留原路由、非法 hash 归一化、重复点击不撑大历史栈、快速连点子菜单不错位（验收清单 UI-005）。任一断言失败退出码 1。
- `data-center-ui-e2e.mjs`：**数据管理界面契约回归（T1 术语 + T2 结构，2026-09-14；第二轮补齐后 67 条）**。用**接口打桩**（只造这一个页面要的数据）跑真实组件，断言"界面上有什么、没有什么"——这类结构性契约后端测试看不见（它不渲染）。67 条断言：列表行样本数取 `weld_count`（不是切片数）；T10 切分页（单位默认帧、切片时长给「10 帧 = 0.400 秒」、时序窗口 4,000 采样点 @10 kHz、页面不再出现「帧 ≈ 时分秒」）；T9 列表搜索走服务端（关键词不匹配回空页）+ 分页器存在；T8 版本行显示构建中/构建失败并给「重新构建」、构建中的行不可进入；T4a 登记改造（未带上下文先走「选择所属数据集」步骤 → 锁定只读；默认值带「默认」标记；从上传 CSV 推导采样率 2 kHz；提交前弹默认值确认；结果卡三个出口；继续登记保留上下文并清空表单）；概览统计卡是「样本数 + 切片数」两张；有效切片占比读后端 `effective_ratio`（25.0%，**不是** `1-三项之和`）、列出影响最大的原因、展开 3 条明细含 `affected`；「字段完备性」面板存在且维度名中文、「模型适配检查」面板与"可训练"结论已消失、保留划分策略；整页无被禁术语；成员表/全部样本表都不再有「核验状态」列，送丝/焊接速度为两列带单位；**T6 骨架**（概览/成员/登记页的面包屑用词、面包屑「数据集」可点回列表、上下文条用 `.context-bar`）；**T5 守卫**（无数据上下文时选择器 `.needs-attention` + 提示文案、S3 按钮「在本页选择数据」点后不跳走、从成员详情进核验自动带入该条样本）；**T4b 登记载荷**（电流/电压是两个独立输入框、提交体带 `current_a`/`voltage_v` 数字、厚度剥单位、不再带旧 `current_voltage`）；**T4.4 导入状态**（结果卡显示「导入失败」并列出失败文件、点「重新导入」调后端、状态回到「可分析」）；**R5 选择器分页**（分析「选择数据」首页只渲染 20 条、给「加载更多（共 25）」、翻页后第 21–25 条可达、取完末页按钮消失）。**六个坑**：概览从成员页返回时是**重新挂载**，版本行要等接口回来（等容器不够，要等 `.dataset-version` 行）；切分页的采样率来自异步 `/signals`，断言前要先 `waitForFunction` 等它落地，否则读到 1000 Hz 的兜底值：`DatasetWorkspace` 用 `dataset_no`（不是数字 id）请求详情，打桩路径要按它写（否则详情返回错形状 → 页面直接崩）；成员表空成员时是空态、不渲染表格，要断言表头就得先给一条成员；`/welds/{id}` 的单条详情规则必须写在 `/welds` 列表规则**之前**，否则详情拿到分页对象、`record.modalities.join` 直接崩；**数据上下文与数据集内部层级都不入 URL**，所以"回到无上下文状态/回到列表视图"只能用 `page.reload()`——`page.goto()` 到同一 URL 不会重载，页面仍停在原视图（用 `waitForStep`/`clickStep` 定位卡在哪一步）。
- `t3-error-state-e2e.mjs`：**T3 错误态实机验收**（2026-09-14）。两种模拟：① **断网模式** `route.abort()` 全量模拟后端停机 → 数据集列表 / 数据登记 / 分析「选择数据」三页断言 `ErrorState` + 重试 + 表格为空 + **整页无任何旧演示数据字面量**（`DEMO_STRINGS` 白名单式反查，含 8,420 / 93.3 / Fronius CMT / WLD-20260815-0248 等）；② **拦截模式**只放行 `/datasets` 与 `/welds`，其余照旧停机 → 先进入数据核验页并用页顶选择器补上下文（T5 恢复路径），再断言该页错误态、评分占位 `—`、无演示规则、S12 导出禁用；T4a 起登记页在数据集不可用时停在「第 1 步：选择所属数据集」（断言仍停在步骤页、确认按钮禁用、未进表单）。25 条断言。

## 调用链

- 被谁调用：手动/验收脚本调用；`browser-history-e2e.mjs` 需先起前端（`npm run dev -- --port 5199 --strictPort`），用 `E2E_BASE_URL` 指定其它地址（默认 `http://localhost:5199`）。
- 调用谁：`generate_training_signal.py` 无依赖；`browser-history-e2e.mjs` 用 devDependencies 里的 `playwright`（浏览器已装），通过 `localStorage.token` 绕过登录闸门，后端可不起（页面走加载失败态，路由断言仍有效）。

## 关键规则/坑

- 输出路径锚定仓库根 `data/`（`parents[1]`），与 cwd 无关。
- 脚本目的明确、无副作用的工具放本目录；需长期维护的生成器再考虑迁入 `backend/tests/fixtures/` 或 `app/services`。
- `browser-history-e2e.mjs` 里有一段**预热加载**：vite dev 把 `lucide-react` 排除在预打包外，冷启动首次导航可能数十秒，不预热会把冷启动误判成失败。脚本用 `.nav-subitem.active` 文本 + `location.hash` 断言，比断言页头更稳（数据管理各子页共用同一页头）。
