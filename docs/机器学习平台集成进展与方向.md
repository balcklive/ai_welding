## 二、鉴权机制备忘（集成必读）

### Label Studio —— 必须"用户账号 + API key"
- **两类 key**（Account & Settings 生成，均绑定"某实例的某用户"）：
  - **Personal Access Token (PAT)** = JWT refresh 型，OSS 默认极长有效期；HTTP 直接调 REST 需先 `POST /api/token/refresh {refresh}` 换 ~5 分钟 `access`，用 `Authorization: Bearer <access>`；**配官方 `label-studio-sdk` 时设一次即可**（SDK 内部处理刷新）。
  - **Legacy Token** = 不轮换、长期，`Authorization: Token <token>` 直接用。
- PAT **只显示一次**，需即时安全保存；重新登录/再生成会拉黑旧 refresh。
- 主应用集成：`.env` 加 `LABEL_STUDIO_URL` + `LABEL_STUDIO_API_KEY`，SDK/REST 读取即可；**每个新部署的 LS 实例都要在该实例内重新生成 key**，不可跨实例复用；建议专用集成账号 + Legacy（或 PAT）并单独吊销。

### MLflow —— 默认无需鉴权；可选"用户账号+密码"，无 API key 概念
- **默认 Tracking Server 无鉴权**（谁能连上谁就能读写实验）。当前我们部署的 mlflow 即默认无鉴权，且宿主 8225 暴露公网 → **安全注意点**（见方向四）。
- **可选 basic-auth**：`mlflow server --app-name basic-auth` + `basic_auth.ini`（`default_permission`/`database_uri`/`admin_username`/`admin_password`）+ `MLFLOW_FLASK_SERVER_SECRET_KEY`；首次启用生成内置 `admin/password`。用户管理走 `/api/2.0/mlflow/users/*`（admin 才能建用户）——是**账号+密码**，不是"申请 API key"。客户端用 `MLFLOW_TRACKING_USERNAME`/`MLFLOW_TRACKING_PASSWORD` env。
- 主应用集成现在无需凭据（compose 内网 `mlflow:5000`）；多用户/外网暴露时再开 auth 或反代 OAuth。

### 踩过的坑（务必避免重犯）
1. **LS PAT 不能直接当 API key 用**：它是 refresh 型 JWT，`Authorization: Token <PAT>` = **401**；须 `POST /api/token/refresh/ {refresh}` → `Bearer <access>`，或**配官方 SDK**（`api_key=<PAT>` 内部自动 refresh）。此前误用 `Token` 头打 401 浪费了排查。
2. **LS 1.23 用户表是 `htx_user`，且无 access token 列**——API token 走登录/refresh，**不存 DB**；别指望从数据库取 access token，应从 UI/登录接口获取或直接用 PAT + SDK。
3. **`.env` 初始没有 `LABEL_STUDIO_API_KEY`**（服务器 `.env`、本地 `.env`、LS 容器环境都无）——集成前必须先配 LS 集成账号 token（当前用 user_id=1 的 PAT；安全收敛建议换专用集成账号）。
4. **LS 项目4 原为 BrushLabels**，与平台 `kind=polygon` 不一致——已改 PolygonLabels；若不改，回写需掩膜→轮廓（有损 ~0.16%，且平台 `annotations` 无掩膜/rle 列）。
5. **服务器 `/tmp` 上 scp 的文件 `rm` 报 `Operation not permitted`**（sudo 不可用）——宿主临时文件删不掉（无碍，重启即清）；容器内 `docker exec rm` 可删。
6. **迁移 head 截至 `0012`**，新迁移必续 `0013`（down_revision=`0012`）；`ADD COLUMN ... NOT NULL DEFAULT` 一条同时完成存量回填 + 新行默认 + 蓝绿 expand 兼容，**不要**再拆成"可空列 + 单独 UPDATE + contract"。
7. **熔池入 `label_categories` 后，`pretag_sample`（`app/services/annotation.py:254`）会从全部类别抽类做 AI 预标注**——会把「熔池」当 bbox 类别随机标到检测任务。需按任务/`kind` 收窄类别集（**未解决，记坑**）。
8. **数据集构建"标注已回写"闸门需要任务级聚合完成谓词**（N 样本全 synced？阈值？）——计划只写原则，机制未定（**待 writing-plans 定**）。
9. **时序标注媒体 = 专用导出 CSV**（选列 `time,cur,vol,gas,wir[,weld_speed]`、降采样 ≤~2 万行、显式 time 秒）——生成链路现无，时机（同步/后台）待定（**待 writing-plans 定**）。
