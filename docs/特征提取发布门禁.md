# 特征提取第二阶段发布门禁

发布前在 `backend` 目录执行：

```bash
uv run python scripts/feature_release_gate.py --probe
```

门禁要求：

- `FEATURE_VISION_PROVIDER_URL` 指向已审核的正式视觉推理服务；
- MySQL、MinIO 的连接配置完整，`--probe` 可连通；
- `SEED_DEMO=false`，并修改 `SECRET_KEY`、`ADMIN_PASSWORD` 默认值；
- 生产镜像安装 PyTorch，以支持 PT 导出；
- 执行 `uv run alembic upgrade head` 后，再运行特征提取、导出和重试验收；
- 前端执行 `npm run typecheck && npm run lint && npm run build`；
- 后端执行特征/Job 测试，并用真实输入完成一次异步任务、历史查询、JSON/CSV/NPY/PT 导出和失败重试。

脚本默认只做配置检查，不访问外部系统；只有显式传入 `--probe` 才会探测 MySQL 和 MinIO。
