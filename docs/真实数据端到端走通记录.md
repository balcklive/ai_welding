## 3. 数据适配发现（实测，勿跳过）

示例数据**原样**导入会触发信号校验 fail（overall=fail，R5/R6/R9 三条失败），原因不是数据坏，而是平台此前按演示数据定死的两个假设：

### 3.1 `time` 列格式 → 采样率推导（R6）

- 实测：`time` 为 ISO 时间戳字符串（`2026-06-17T14:22:23.000164Z`），`pd.to_numeric(…, errors="coerce")` 得到全 NaN → R6「采样一致性」fail「时间列无有效递增差值」→ fs 推导不出 → R9 最小时长连带 fail。
- **适配**：导入前把 `time` 转成相对数值秒（首条置 0，`(t-t0).total_seconds()`）。产物 `data/SP2026-06-000201/timeseries_prepared.csv`（5kHz 均匀、无抖动、182s）。

### 3.2 通道量程 → 量程校验（R5）

- 实测：`CHANNEL_SPECS` 原为演示档 电流 0–300A / 电压 0–40V（容差 ±10%），真实 MAG 短路过渡峰值 **电流 532A / 电压 70V** → R5 有 253142 点超限 fail。
- **适配**：`backend/app/services/signals.py` 将 `CHANNEL_SPECS` 放宽到真实焊接范围——电流 **0–600A** / 电压 **0–80V** / 气体 **0–60 L/min** / 送丝 **0–20 m/min**（前端 y 轴经 channel.lo/hi 读取，随之放宽）。

### 3.3 连带修复：事件检测阈值与边界伪异常

放宽量程后暴露两个 `signal_ingest.py::detect_events` 问题（2 个既有测试失败），已一并修复：

1. **阈值改按信号自身幅度推导**：原 `on_thr = baseline + 0.25*(hi-lo)` 用物理量程 span，放宽后 span 与信号幅度不再成正比，低幅信号会误判整个焊接段失活。改为 `span = p95 - p10`（数据自适应），对低幅焊种（如 TIG 小电流）更稳健。
2. **异常检测剔除边界过渡区**：起弧/收弧 ramp 在居中滚动窗下横跨 idle→active，std 必然虚高 → 边界伪异常段。改为只在焊接段内部（剔除滚动窗半宽 `trim=W`）判异常，索引回推整段坐标。

### 3.4 列名未识别（不致命）

`GasSpeed`/`tag0`/`tag1` 不在表头别名表 → 仅 R2 表头识别 **warn**（overall=warn 仍写 Parquet 供分析），但该列**不会被导入为通道**——本次导入后只有 cur/vol 为真实信号，gas/wir 补零。想映射气体流量，把列改名为 `gas` / `气体流量` 即可（`services/signal_ingest.py` 的 `_HEADER_ALIASES`）。
