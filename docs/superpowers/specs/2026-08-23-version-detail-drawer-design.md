# 版本详情抽屉设计

## 目标
为数据中心的焊缝数据版本和数据集版本补上“查看”交互，让用户能在当前上下文快速核对版本内容，而无需离开版本链。

## 交互方案
- 点击焊缝版本“查看”打开右侧详情抽屉。
- 抽屉展示版本号、处理动作、创建时间、操作人、备注、当前版本标识、文件/模态信息与核验结果。
- 核验尚未执行时展示“尚未执行核验”，不视为页面错误。
- 点击数据集版本“查看”打开同一抽屉组件的快照变体。
- 快照变体展示版本号、样本数、训练/验证/测试划分、质量、快照 ID 和可用的固定样本信息。
- 点击遮罩、关闭按钮或 Escape 关闭抽屉；抽屉打开期间背景不可滚动。

## 数据流
- 焊缝版本：调用 `getVersion(weldId, versionId)`，并尽力调用 `getValidation(weldId, versionId)`。
- 数据集版本：调用 `getDatasetVersion(datasetId, versionId)`。
- 加载失败时在抽屉内显示明确错误，并保留关闭能力。
- 当前已有 mock 数据继续作为初始态，API 成功后替换详情数据。

## 验收标准
- 所有非当前焊缝版本的“查看”按钮均有可见响应。
- 所有非当前数据集版本的“查看”按钮均有可见响应。
- 详情数据不会与列表当前版本状态混淆。
- TypeScript 类型检查和生产构建通过。
