## 2. 核心规则

1. **前后端零交叉**：前端只认 `src/`，后端只认 `backend/`，互相不 import；通信仅走 HTTP `/api/v1`。
2. **接口契约唯一来源**：`docs/API接口清单.md`。改动接口 = 先改文档，再同步两端代码。
3. **路由与前端函数一一对应**：`backend/app/api/v1/<域>.py` ⇄ `src/api/<域>.ts`（见 §3）。
4. **敏感配置只进 `.env`**：`.env` 被 gitignore；`.env.example` 作为无敏感值模板入库，新环境复制后填写。
5. **每目录必有 CLAUDE.md**：记录脚本/功能/坑与限制（项目既定规则）。
6. **异步任务统一放 `backend/app/jobs/`**：对外暴露统一 Job 状态接口（`GET /jobs/{id}`）。

## 4. 命名约定

- **后端**：文件/函数/变量 snake_case；Pydantic schema 类名 PascalCase。
- **前端**：文件/函数 camelCase；TS 类型名 PascalCase；接口函数 `动词 + 资源`。
- 每个业务域一个路由文件 + 一个前端接口文件，文件内函数与 `docs/API接口清单.md` 的端点一一对应。

## 5. 构建与部署文件

- `Dockerfile`（仓库根，多阶段）：
  1. `node:20-alpine` 构建前端 → `dist/`
  2. `python:3.12-slim` 安装后端依赖（uv）
  3. 合并：FastAPI 挂载 `dist/` 为静态资源，`uvicorn` 单进程服务 `/api/v1` + 前端
- `.github/workflows/deploy-docker.yml`：`main` 校验（lint/typecheck/build）通过后构建推送阿里云 ACR，再经 SSH 在服务器 `docker pull` + `docker run`；服务器需配置项目 `.env`。MinIO/MySQL 已远程，容器只跑应用。
- 上传文件落 MinIO；DB 用远程 MySQL。
